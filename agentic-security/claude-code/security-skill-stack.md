# Claude Code Security Skill Stack

Tags: claude-code, skills, security-reports, knowledge-base, code-graph, repeatable-workflows

A practical security skill stack covers five jobs:

- **Report editing:** remove generic AI phrasing while preserving evidence and the operator's voice.
- **Knowledge capture:** distill reports, timelines, research, and investigation notes into linked, searchable pages.
- **Codebase mapping:** inventory modules, interfaces, data flows, and trust boundaries.
- **Process encoding:** turn checklists into repeatable methods with inputs, steps, stopping conditions, and output.
- **Skill discovery:** search community catalogs before rebuilding a mature workflow.

Prefer a small reviewed set over importing a full catalog. Examine every skill's instructions, scripts, dependencies, and external requests before enabling it. Useful security skills preserve scope, avoid invented evidence, and separate discovery from validation.
